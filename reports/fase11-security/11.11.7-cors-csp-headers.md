## Cockpit (Cloudflare Pages) — recomendação
Outra branch adiciona `apps/zylos-cockpit/_headers`; não alterado aqui. Recomendação mínima:
```
/*
  Content-Security-Policy: default-src 'self'; script-src 'self' 'wasm-unsafe-eval'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; connect-src 'self' http://127.0.0.1:3000 ws://127.0.0.1:3000 http://localhost:3000 ws://localhost:3000; frame-ancestors 'none'; base-uri 'self'; form-action 'self'; object-src 'none'
  Strict-Transport-Security: max-age=31536000; includeSubDomains
  X-Content-Type-Options: nosniff
  X-Frame-Options: DENY
  Referrer-Policy: strict-origin-when-cross-origin
  Permissions-Policy: camera=(), microphone=(), geolocation=()
  Cross-Origin-Opener-Policy: same-origin
```
Notas: `'wasm-unsafe-eval'` é necessário para o bundle Leptos/WASM; evitar `'unsafe-eval'`. `connect-src` deve listar o gateway real. Observação: como `local_guard` recusa Origin não-local, o cockpit hospedado em `*.pages.dev` **não** consegue chamar o gateway loopback — o `connect-src` só é útil para o cockpit servido localmente ou se o gateway passar a aceitar a origem do Pages (que exigiria JWT obrigatório, ver 11.11.4 §6).
