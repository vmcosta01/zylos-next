# 11.11.3 — Validação do filtro de egress

**Código:** `crates/zylos-agent-shield/src/network_egress.rs` (commit 1406acd). 30 testes no módulo.

## Tentativas de bypass cobertas (todas bloqueadas em teste)
| Técnica | Exemplo | Mecanismo | Teste/local |
|---|---|---|---|
| IPv4 decimal/hex/octal/curto | `2130706433`, `0x7f000001`, `0177.0.0.1`, `127.1`, `0xA9FEA9FE` | parser estilo `inet_aton` | `network_egress.rs:364`, `:417`, testes `:1026-1034` |
| IPv6 / IPv4-mapped | `[::1]`, `[::ffff:127.0.0.1]` | `is_internal_ip` | `:332`, teste `:1153` |
| userinfo | `http://allowed.com@127.0.0.1/` | rejeição de `@` | `:575`, testes `:1079`, `:1125` |
| caracteres proibidos | `\`, `%`, `#`, `?`, espaço, controle | `normalize_host` | `:414` |
| Redirect para interno | `Location: http://169.254.169.254/` | `check_redirect` trata cada salto como nova requisição | `:150`, teste `:1165` |
| DNS rebinding | nome público resolvendo para IP interno | `check_resolved` / `check_with_dns` valida os IPs efetivamente resolvidos | `:160-203`, teste `:1183` |
| Nomes internos | `localhost`, `*.local`, `*.internal`, metadata | `is_internal_name` | `:468` |
| Erro de parse | host malformado | fail-closed (deny) | `:450` |

**Execução real:** `cargo test -p zylos-agent-shield` → **123 passed, 0 failed**.

## Limitações / riscos residuais
1. **Não integrado (Alto):** nenhum cliente HTTP do workspace chama `NetworkEgressFilter::check_url`/`check_with_dns` (grep em `crates/` e `apps/` só encontra o próprio módulo). O filtro só protege quem o invocar.
2. **TOCTOU de DNS (Médio):** `check_with_dns` resolve e valida; se o cliente HTTP resolver de novo, um rebinding com TTL 0 ainda passa. Correção: conectar no IP validado (resolver customizado do reqwest / `resolve()` fixo).
3. **Redirects (Médio):** exige cliente com `redirect::Policy::none()` ou policy que chame `check_redirect` — documentado em `network_egress.rs:132-136`, não imposto.
4. Wildcards de allowlist de hosts são tratados em capability tokens (ver 11.11.6).

**Veredito:** lógica de filtro aprovada; critério "egress bloqueia todos os bypass testados" cumprido **no nível da unidade**, não fim-a-fim.
