# 11.11.9 — Auditoria adversarial (tentativa de refutar cada correção)

Revisor: subagente (não independente do autor das correções — limitação declarada). Método: releitura do código corrigido procurando bypass.

| Correção | Tentativa de refutação | Resultado |
|---|---|---|
| F1 bootstrap login | Brute-force do bootstrap token; timing | `ct_eq` (`apps/zylos-gateway/src/auth_api.rs:113-118`) vaza só o comprimento; token ≥32 B torna brute-force inviável, mas **não há rate limit** → residual Baixo. Bootstrap é credencial única compartilhada (sem usuário) → quem a tem cunha admin. **Mantida, com ressalva.** |
| F2 segredo | Iniciar sem `ZYLOS_AUTH_SECRET` | 503 em todos os endpoints de auth (`auth_api.rs:78-85`). **Não refutada.** |
| F4 alg confusion | Token `alg: none` / HS512 com config HS256 | `Validation::new(self.config.algorithm)` (`crates/zylos-auth/src/tokens.rs:314`) aceita só o algoritmo configurado. **Não refutada.** |
| F4 refresh reuse | Duas requisições concorrentes com o mesmo refresh | `get_mut` do DashMap é exclusivo por shard (`tokens.rs:242-260`); a segunda vê `used=true` e revoga a família. **Não refutada.** Residual: access tokens já emitidos da família continuam válidos até expirar (≤15 min). |
| F4 revogação | Restart do gateway | Denylist em memória é perdida → access token revogado volta a valer até `exp`. **Refutada parcialmente (Médio).** |
| F3 wasmtime 36 | API WASI mudou (`WasiView` removido em a29e21e) — política de FS/rede mantida? | 12 testes de sandbox passam (incl. `test_network_policy`, `test_resource_limit_memory`); preopens não reauditados linha a linha. **Mantida.** |
| F5 egress | `%2e`/percent-encoding, IDN/punycode, TOCTOU de DNS | `%` rejeitado no host (`crates/zylos-agent-shield/src/network_egress.rs:414`); IDN não normalizado (homógrafo é risco de allowlist, não de IP interno); **TOCTOU de DNS não resolvido** se o cliente re-resolver. E o filtro **não é chamado** em produção (F11). **Refutada no nível de sistema.** |
| F6 capability path | `/data/%2e%2e/etc`, symlink, maiúsculas no Windows | `..` literal bloqueado (`capability_token.rs:112`), mas percent-encoding não é decodificado — se o consumidor decodificar após autorizar, há bypass; symlinks não resolvidos; `C:\DATA` vs `/data/*` nega (fail-safe). **Residual Médio** (consumidor deve canonicalizar antes de autorizar). |
| F6 network wildcard | `*.example.com` vs `example.com.evil.net`, `evilexample.com` | fronteira de ponto exigida (testes `capability_token.rs:752-770`). **Não refutada.** |
| F7 headers | Respostas que não passam pelo middleware | `security_headers` é a camada mais interna (`apps/zylos-gateway/src/lib.rs:222`); respostas 403 de `local_guard` (`lib.rs:233`) e preflight CORS **não recebem** os headers. **Refutada parcialmente (Baixo)** — mover a camada para fora. |
| F8 deny.toml | Allow-list permissiva demais esconde copyleft | MPL-2.0 é a única copyleft aceita; GPL/LGPL só aparecem em expressões `OR` com alternativa permissiva. **Não refutada.** |
| local_guard | Reverse proxy / cliente não-browser com `Host: localhost` | Não-browser forja `Host` livremente; proxy reescreve Host → **guard é anti-browser, não autenticação**. **Refutada como controle de acesso** (já registrado como F9). |

## Riscos residuais (aceitos/abertos)
1. F9/F10: gateway confia em qualquer processo local; reverse proxy anula a premissa (Alto/Crítico se exposto).
2. F11: egress filter não integrado; TOCTOU de DNS.
3. F13/F12: 12 vulns de dependência (2 high quick-xml, DoS).
4. Estado de auth em memória (revogação perdida no restart; sem multi-instância).
5. Capability tokens sem assinatura e sem integração HTTP (F16).
6. Sem rate limiting (F15).

## Veredito
**NÃO APROVADO para produção exposta.** Correções críticas (F1, F2, F3) verificadas e mantidas; altos remanescentes (F9, F10, F11, F13) impedem o critério "zero críticos/altos não remediados" e "auditoria adversarial retorna APPROVED". Aprovável **condicionalmente** para uso local (bind 127.0.0.1, sem proxy). 11.11.10 (sign-off) não deve ser assinado até F9–F11 serem resolvidos.
